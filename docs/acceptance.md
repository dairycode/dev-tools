# 验收清单

基线：main `cf3a500`。要求：现有能力不减少、UI 不劣化、Docker 可部署。

## 功能矩阵

| 工具   | 必须保留                                                                  | 改善与边界                                                                          |
| ------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| URL    | 编码、解码、URI 编码、原地转换、清空、Ctrl/Cmd+Enter                      | 非法百分号不覆盖输入；新增复制                                                      |
| Base64 | 编码、解码、原地转换、清空、快捷键                                        | UTF-8 中文/emoji、大文本；Latin-1 兼容模式保留旧字节语义                            |
| Hash   | MD5/SHA-1/SHA-256/SHA-512、实时计算、算法切换、清空、复制、快捷键         | 默认保留去首尾空白行为，提供精确原文模式；标准向量验证                              |
| 时间戳 | 默认当前时间、双向转换、自动单位、日期/时间输入、当前按钮、分别清空       | 显式单位、完整数字校验、0/负值、秒/毫秒、跨时区/本地日期、分别展示北京/本地/UTC/ISO |
| 二维码 | 输入、快捷键、生成、加载状态、预览、PNG 下载、清空                        | 失败/输入变更不下载旧图，过期任务不覆盖新结果，扫码验证内容                         |
| JSON   | 自动解析、2 空格格式化、压缩、原地转换、树形节点、折叠/展开、清空、快捷键 | 全部展开/折叠按钮、合法标量根、大整数/小数精度、键路径碰撞保护、树规模保护          |

## UI 与通用交互

- 桌面侧栏保持纵向；手机导航为单行左右滑动、工具名不换行，选中及聚焦项完整可见，六工具均可访问，无页面级横向溢出。
- 常见桌面窗口六工具初始内容完整一屏展示；长输入/结果、手机及窄窗口允许滚动，滚到边界不继续回弹，不裁剪内容。
- 保留原蓝色系、明暗主题、清晰文本与足够的输入空间；手机减少旧版顶部空白。
- 单按钮按「跟随系统 → 亮色 → 暗色」循环并显示当前状态；系统响应、刷新持久化、旧存储键、存储拒绝均正常。
- 页面去除重复介绍、隐私徽章、标语、计数和常驻快捷键说明；保留必要标签、错误反馈、数据限制和原有快捷键。
- 页面装饰图标统一使用共享 SVG，明暗主题下继承文字颜色；不把用户输入中的 Unicode / emoji 当成装饰内容删除。
- 所有输入有 label、按钮可键盘访问、焦点可见、提示可被辅助技术读取。
- GitHub 和 ICP 备案链接保留；首屏无 favicon 404。
- 复制真实成功后才提示成功；失败不丢输入，可继续手动复制。
- 不向外部请求传输输入，不存输入历史，不注入未转义 HTML。
- hash 直达/刷新/前进后退正确；切换工具重置输入，与旧版保持一致。
- 六个工具全部同步加载，首次切换也不请求工具脚本、不出现加载占位。
- 所有下拉框使用页面自绘弹层，箭头居中并统一右侧留白；明暗主题、触屏、键盘选择与取消、焦点移出、视口边缘均正常。

## 工程与部署

- 类型检查、lint、格式、单测/覆盖率、生产构建全部通过。
- Chromium / Firefox / WebKit 桌面及手机核心流程通过；截图/自动无障碍检查留证。
- 同设备同输入对照旧版，记录首屏资源和操作耗时，不伪造性能结论。
- 根目录与子目录静态部署通过。
- Docker 实际构建、非 root/只读启动、健康检查、MIME/缓存/404、容器浏览器 E2E 通过。
- 按用户明确要求使用 Tailwind 4，不保留旧浏览器兼容承诺；实际验证现代 Chromium、Firefox、WebKit。
- 不留临时调试代码、服务器进程或测试容器。

### 移动端单行导航复验（2026-11-21，当前版本）

- 仅移动端导航改为单行原生横向滚动，工具名不换行、不收缩；隐藏滚动条并禁止边界回弹，桌面仍为原纵向侧栏。路由选中或键盘聚焦的链接会完整滚入可见范围，不横向滚动整个页面。
- `npm run verify` 通过：15 个单元/组件文件、177 项测试；真实非 root/只读 Docker 根目录五项目 **230 项**、子目录 Chromium **46 项**通过，无跳过、无重试。
- 新增 3 项组件测试及 3 项浏览器用例（五项目共 15 项）：320/390px × 明暗主题单行/触控高度/局部滚动、直达刷新/前进后退自动显露、聚焦/键盘确认，以及 767/768/1024/1440px 断点和桌面侧栏。WebKit 用 Option+Tab 遍历链接，遵循系统键盘约定，不关闭焦点检查。
- 浏览器原生焦点移动可能只把链接的一小部分滚入可见范围；因此聚焦时也显式调整导航 scrollLeft，保留完整的工具名和焦点轮廓，不仅在选中变化时处理。
- Chrome 158 CDP 模拟触摸横滑后导航 scrollLeft 为 255px，整页 scrollX/scrollY 均为 0，页面宽度仍为 390px；这是模拟手势，不是真机。复查桌面/手机、明暗代表图，更新 38 张本地截图，另存 12 张 320/390/1440px 首尾工具截图及触摸记录于被忽略的 `artifacts/mobile-navigation/`。
- 本轮未重测首屏资源/耗时，`performance.json` 的 `unifiedWorkspace` 仍是上一轮数据；未执行真机或远端部署。现有 8080 容器及 Git 暂存内容未改动，自建验收/截图容器已清理。
