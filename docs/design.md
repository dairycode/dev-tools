# React 工具箱重构设计

## 目标与基线

旧版基线为 main 的 `cf3a500`。六个工具、URI 编码、快捷键、即时 Hash、时间戳双向转换、二维码 PNG、JSON 树、主题与备案链接必须保留。只优化，不接受回归。新旧截图与验收记录见 acceptance.md。

## 技术决策

- React 19 + TypeScript strict、Vite 8；不引入 SSR、后端、账号、全局业务状态库。
- 用户明确选择 Tailwind CSS 4，不考虑旧浏览器兼容。使用 @tailwindcss/vite、CSS-first 主题令牌，不引入 legacy/polyfill 构建层；验收目标为现代 Chromium、Firefox、WebKit。
- 样式采用工具类优先：布局、间距、尺寸、断点和状态放在 React 组件中，`styles.css` 只留 `@theme`、暗色令牌覆盖、全局基础样式和减少动画的特殊规则，不再通过大量语义类与 `@apply` 转写 Tailwind。`Controls.tsx` / `Panels.tsx` 承载真实重复的输入、按钮、字段、卡片、错误和结果面板；仅共用输入外观及按钮/链接共同外观使用小型类名常量，不引入样式框架或新依赖。
- 明暗主题统一使用 `--color-*` 令牌；主操作按钮的深蓝色独立于会随主题变化的文字品牌色。状态使用 Tailwind 的 hover / focus / disabled / aria / data / group 变体，完整类名字面量保证构建扫描可见。运行时文本框高度、下拉菜单可用高度、JSON 层级缩进继续使用必要的动态 style。测试优先按角色/名称定位，少量非语义容器用 data-slot，不依赖已移除的样式类。
- TypeScript 5.9 与 typescript-eslint 的兼容范围匹配，不机械追逐不兼容的最新大版本。
- Playwright 固定 1.64.1：1.65.1 的 Firefox 159 在 macOS ARM 上进行 JSON 页 axe 扫描时原生崩溃；同页用 1.64.1 / Firefox 157 完整扫描通过。没有跳过断言、禁用规则或修改页面来掩盖问题。
- 采用轻量 wouter 的 hash 路由，提供 `#/url` 等工具直达、刷新、前进后退。初版 React Router 增加了不必要的首屏体积，验收阶段换用轻量路由，保留同样的导航行为。Vite 相对 base 支持根目录和子目录；输入内容绝不进入 URL。
- registry 是导航、标题、图标和入口的唯一来源。按用户体验要求，六个工具全部静态导入，移除 lazy / Suspense，不在首次切换时请求工具脚本或显示加载占位。代价是首屏脚本增加，不把同步切换等同于弱网首屏更快。每工具独立目录，纯 model 与 React 页面分离；工具不互相依赖。
- 保留单个文本框原地编码/解码交互；新增明确的复制按钮，不以改造为由删旧操作。切换工具重置输入，与 main 一致。
- 主题存储沿用 dev-tools-theme，兼容 light/dark；system 表示跟随系统。单个 ThemeToggle 按「跟随系统 → 亮色 → 暗色」循环，文字和图标表示当前偏好，可访问名称及悬停提示说明下一状态；系统偏好下始终显示系统图标，不因当前系统深浅而误显示成手动模式。首屏预先应用主题；正确清理媒体事件监听。
- 页面精简：只保留标题、表单标签、操作、结果和必要的错误/限制提示；去掉重复副标题、宣传与隐私标语、字符计数和常驻快捷键说明，快捷键功能仍保留。URI 编码区别、时间戳自动单位等细节放在相关控件的悬停提示与 README 中，不再铺满页面。
- 布局采用动态视口最小高度；右侧最大宽度统一为 960px，桌面顶部留白为 `clamp(32px, 20dvh - 96px, 96px)`，高窗口舒展、矮窗口收紧，所有工具标题和卡片起始线一致，不根据工具内容高度分别垂直居中。文本编辑工作区复用 TextEditor：标签与编码/算法设置在顶部，桌面初始文本框最小高度为 `clamp(180px, 30dvh, 256px)`，底部操作以细分隔线分区；手机维持紧凑排布，设置不足一行时自然换行。
- 宽度 ≥1024px 时，时间戳两组转换并排，二维码输入与预览左右排布并拉齐预览高度，常见桌面窗口初始一屏展示。长文本仍自动增高并保留内层滚动，结果向下扩展，不反向移动标题。窄屏自然纵向排列，不缩小字号、不裁剪内容或固定页面高度。
- 移动端（宽度 <768px）工具导航为单行横向滚动，链接不收缩、工具名不换行，滚动只发生在导航内；隐藏滚动条但保留原生触屏滚动。切换、直达/刷新、前进后退及键盘聚焦时，溢出的链接自动完整滚入可见范围；只调整导航的 scrollLeft，不用 scrollIntoView 带动整页。桌面保留纵向侧栏，不改链接语义、路由历史或同步加载方式。
- 根页面、侧栏、导航滚动区、文本框、下拉菜单与 JSON 树使用 CSS overscroll-behavior: none 禁止边界回弹和滚动串联，不用阻止默认触摸/滚轮事件或 overflow: hidden 锁死整页。
- 页面装饰图标统一使用 shared/ui/Icon.tsx 的类型化图标集：24×24 画布、2px 圆角线条、currentColor。导航、品牌、三态主题、下拉框、JSON 折叠箭头、二维码占位、外链与关闭按钮共用，不引入图标字体或外部网络资源；装饰 SVG 对辅助技术隐藏，由所在控件提供名称。
- Toast、输入框、按钮、结果面板为共享 UI，只抽实际重复部分。Base64、Hash、时间戳的下拉框统一用页面自绘 Select（combobox / listbox），不使用系统原生 select 弹层。箭头统一留白和垂直居中；支持明暗主题、触屏、方向键、Home/End、首字母跳转、Enter/空格确认、Esc 取消、Tab 确认并继续移动焦点、外部点击收起和视口边缘向上展开。

## 有意纠错与兼容

- URL 保留组件编码和 URI 编码，不静默吞掉非法百分号。
- Base64 默认 UTF-8，增加 Latin-1 兼容模式以保留旧版字节语义；ASCII 结果不变。
- Hash 保留旧版默认 trim 行为，同时提供原文模式，不静默更改已存在的校验结果。MD5/SHA-1 不是密码存储方案。
- 时间戳保留常见秒/毫秒自动识别，并支持显式单位；严格校验完整数字，正确处理 0、负数、本地日期与 UTC。结果分别标注本地时间、北京时间、UTC，避免把本地误称北京。
- JSON 使用无损数字解析，文本格式化/压缩仅改 token 之间的空白，保留长 ID、小数、指数写法、字符串转义和重复键；树视图按旧版语义展示重复键的最后一个值。支持 null 等合法根节点。大输入限制树渲染规模，仍可格式化、压缩和复制，避免无限递归构建 DOM。
- JSON 输入和已提交预览分开保存：编辑或格式化期间保留旧树，500ms 防抖后一次提交解析/错误/规模结果；取消过期定时器，清空输入立即清预览。树不再以输入文本为 key 重挂载，同路径保留展开/折叠，移除旧路径并按原大小策略初始化新路径，滚动容器保持挂载。确认非法或超限时改为相应提示，不长期把旧树冒充当前结果。
- 二维码成功后才可下载；输入改变、清空和异步任务过期后不再展示可下载的旧结果。

## 部署与安全

Node 多阶段构建 → 非 root Nginx 静态服务，端口 8080。运行镜像不含源码、node_modules。只读文件系统，临时目录单独挂载。入口不缓存，带指纹资源长期缓存，缺失资源返回 404 而不是 HTML。提供健康检查。无运行时 API 地址，不增加不必要的 env 注入；VITE_* 不是秘密。

## 验证

纯逻辑/浏览器适配器单测与覆盖率门槛，组件交互测试，Chromium/Firefox/WebKit 桌面与手机 E2E，明暗主题、键盘、剪贴板拒绝、二维码下载、JSON 边界、子目录和 Docker HTTP 验收。自动检查不能证明主观 UI 优于旧版，必须保留截图并人工对照。实际执行结果单独记录，不把计划当作已通过。
